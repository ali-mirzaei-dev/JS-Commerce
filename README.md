# JS-Commerce | Developer Store

A dynamic, state-driven e-commerce storefront built entirely with **Vanilla JavaScript**.

This project simulates a real-world shopping cart experience, allowing users to add products to a live cart, view dynamically calculated totals, and remove items on the fly.

## Features

- **Live Shopping Cart:** Add products to the cart and watch the UI update instantly.
- **State-Driven DOM:** The cart UI is completely decoupled from the static HTML and dynamically rendered from an array of objects.
- **Dynamic Pricing:** Total price and item counters are automatically recalculated whenever the cart changes.
- **Remove Items:** Remove products from the cart and automatically update the totals and item counters.
- **Responsive Design:** Built with a mobile-first approach using Tailwind CSS.
- **Premium UI:** Clean, boutique-style light-mode design featuring a custom beige and bronze color palette.

## Tech Stack

| Technology | Purpose |
